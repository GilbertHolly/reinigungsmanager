REINIGUNGSMANAGER – PROTOTYP 1.0

Enthalten:
- Chefbereich und Mitarbeiteransicht
- Wohnungen lokal anlegen
- Mitarbeiter lokal anlegen
- Wohnungen für einen Tag einplanen und Mitarbeitern zuweisen
- Mitarbeiteransicht mit Start/Ende je Wohnung
- Status und Zeitdauer
- Speicherung im Browser auf diesem Gerät

WICHTIG:
Dies ist ein klickbarer Frontend-Prototyp. Daten werden nur lokal im Browser gespeichert.
Es gibt noch keine echten Konten, Rollen-Sicherheit, gemeinsame Cloud-Datenbank oder Synchronisierung zwischen Smartphones.
Für den echten Betrieb müssen wir als nächsten Schritt Authentifizierung, Datenbank, Rechteverwaltung und sichere Zeiterfassung ergänzen.

Test:
1. index.html in einem aktuellen Browser öffnen.
2. Im Chefbereich Wohnungen und Mitarbeiter verwalten.
3. Tag wählen, Wohnung einplanen, anhaken und zuteilen.
4. In die Mitarbeiteransicht wechseln und den Mitarbeiter auswählen.
5. Start und Ende einer Wohnung testen.

Für die Installation als PWA muss das Projekt über HTTPS gehostet werden (z. B. später über einen Hosting-Anbieter).
